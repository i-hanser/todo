# TODO List 应用

一个功能完整的待办事项管理应用，基于 React + Vite + TypeScript 开发。

## 功能特性

- ✅ 添加待办事项（标题、描述、截止日期、分类）
- ✅ 删除待办事项
- ✅ 标记待办事项完成/未完成
- ✅ 查看待办事项列表（分组显示：待完成/已完成）
- ✅ 内联编辑（点击标题、描述、日期、分类即可编辑）
- ✅ 任务分类（工作/学习/生活）
- ✅ 任务排序（按分类和截止日期自动排序，支持拖拽自定义排序）
- ✅ 搜索功能（支持多关键词模糊搜索）
- ✅ 数据持久化（使用 localStorage 保存数据）

## 运行方式

### 环境要求

- Node.js >= 16.x
- npm 或 yarn

### 安装依赖

```bash
npm install
```

### 启动开发服务器

```bash
npm run dev
```

启动后，在浏览器中访问控制台显示的地址（通常是 `http://localhost:5173`）

### 构建生产版本

```bash
npm run build
```

构建产物将输出到 `dist` 目录。

### 预览生产版本

```bash
npm run preview
```

## 技术栈

- **React 18** - UI 框架
- **TypeScript** - 类型安全
- **Vite** - 构建工具
- **CSS3** - 样式（Morandi 色系）

## 使用说明

1. **添加待办**：在右侧表单填写标题（必填）、描述、截止日期、分类，点击"添加待办"
2. **编辑待办**：点击待办项的标题、描述、日期或分类即可内联编辑
3. **完成任务**：勾选待办项前的复选框
4. **删除待办**：点击待办项右侧的"删除"按钮
5. **搜索**：在搜索框输入关键词，支持多关键词搜索（空格分隔）
6. **拖拽排序**：拖动待办项左侧的拖拽图标可自定义排序
7. **重置排序**：点击"待完成"标题旁的"重置排序"按钮恢复自动排序

## 数据存储

应用使用浏览器的 localStorage 存储数据，刷新页面后数据不会丢失。
